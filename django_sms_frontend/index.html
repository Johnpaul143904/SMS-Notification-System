About SMS Sender Gateway

IT120 SMS Gateway Project

This web application is a single-page SMS Gateway client engineered with modern HTML5, CSS3, and vanilla JavaScript.

  • Input Validation: Validates mobile phone numbers (+63 / international E.164 formats) and enforces 160-character SMS constraints.
  • Provider Connectivity: Sends messages to the Django REST API, which communicates with TextBee using backend credentials.
  • Persistent History: Loads SMS transaction records from the Django database; this page does not create local history.
  • Responsive Design: Replicates the desktop layout down to every shadow, badge, and color palette.
